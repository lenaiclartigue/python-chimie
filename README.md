# Modélisation pour la chimie — Python
Site statique pour GitHub Pages. Déposer le contenu de ce dossier à la racine d’un dépôt, puis activer Settings → Pages → Deploy from a branch → main / root. Conserver `.nojekyll`. Tous les chemins sont relatifs, compatibles avec une URL /nom-du-depot/.

Le moteur Basthon et ses principales dépendances sont inclus. SciPy est téléchargé depuis une URL Basthon à version fixe. Une connexion est nécessaire au premier démarrage. Les versions sont figées ; aucune recherche de nouvelle version n’est effectuée à chaque connexion.

Les quatre CSV du TP3 sont fournis et chargés automatiquement sans écraser les fichiers déjà importés. Les notebooks de correction et le fascicule annuel de projet sont exclus du dépôt étudiant.

La sauvegarde utilise le navigateur et l’origine du site : les travaux de la préversion privée ne migrent pas automatiquement sur GitHub Pages. Télécharger puis réouvrir les notebooks et réimporter les données permet de les transférer.
