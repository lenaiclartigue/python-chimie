BIENVENUE DANS L’ATELIER

Votre travail, pas à pas

  1. Lisez l’explication ou la question à gauche.
  2. Écrivez dans une cellule Python à droite. Cliquez sur Exécuter dans Basthon ou utilisez Maj + Entrée.
  3. Ajoutez des cellules de code ou de texte depuis le menu Insertion de Basthon.
  4. Importez vos CSV avec « Importer des données », puis utilisez leur nom dans Python.
  5. Téléchargez votre notebook et conservez vos données avant de quitter le poste.

Les copies locales sont propres à ce navigateur. Elles ne sont pas envoyées à l’enseignant et ne sont pas synchronisées entre ordinateurs.

Un notebook conserve le code et les résultats affichés. Pour reprendre les calculs après un redémarrage, réexécutez les cellules dans l’ordre. Un fichier de données doit être conservé séparément.

Les modes Lecture et Python agrandissent un panneau. Sur téléphone, utilisez ces modes pour passer de l’un à l’autre.
